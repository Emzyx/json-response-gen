# json-response-gen

## Intentions

Some helper functions to generate random data in a JSON shape when you know the shape of data samples but are unable to obtain any examples of it due to potential time or data constraints. 
Should allow for more rapid iterating when design requirements are changing, or development on the data end begins to lag behind. This should allow you to easily modify the shape/template, rerun and once again have usable data samples for whatever purpose.

Library allows for building multiple JSON objects or arrays, with links between data per use case.

## Installation

```

npm install json-response-gen --save-dev

```
